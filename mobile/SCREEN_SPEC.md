# 화면별 구현 명세

공통 기준: 402×886, 흰 배경, 상단 내비게이션, 좌우 주요 여백 24–32px, 하단 주 CTA 303×54px(대체로 x=50, y=796), Noto Sans KR 중심.

## 1. M01 보호자 프로필_계정 연동

- 상단 제목 ‘페타 회원’, 뒤로가기, 닫기.
- PET:A 일러스트/워드마크 후 소셜 로그인 3종: 카카오(노랑), 네이버(초록), Pleos(짙은 남색).
- 하단 ‘페타가 처음이신가요?’와 밑줄 링크 ‘이메일로 회원가입’.
- 로그인 버튼은 각각 독립 액션이며 진행 중/실패 상태를 제공합니다.

## 2. M01 보호자 프로필_여행 스타일

- 제목 ‘태완님은 어떤 여행을 좋아하시나요?’.
- 대표 여행 타입 캐러셀: 현재 ‘산책 마스터’, 설명과 좌우 화살표.
- 2×3 원형 선택 목록: 인생샷 발굴, 1박 여행러, 사계절 투어러, 바캉스 매니아, 산책 마스터, 차박 매니아.
- 다중 선택. 예시는 2개 선택이며 선택 항목은 주황 테두리/컬러 이미지, 미선택은 회색 처리.
- ‘건너뛰기’, 주 CTA ‘2개 여행 취향 선택 완료’. 선택 수에 따라 문구와 활성 상태를 갱신합니다.

## 3. M02 반려견 프로필(1)

- 제목 ‘어떤 친구와 함께 떠나나요?’, 원형 반려견 사진과 추가 버튼.
- 반려동물: 강아지/고양이 단일 선택.
- 입력: 이름, 견종, 몸무게, 생일. 예시 값은 설이, 골든 리트리버, 25kg, 2023. 11. 03.
- 성별: 왕자님/공주님 단일 선택. 중성화 여부: 예/아니오 단일 선택.
- CTA ‘다음’. 필수값이 없으면 비활성 또는 인라인 오류를 표시합니다.

## 4. M02 반려견 프로필(2)

- 제목 ‘보리의 여행 습관을 알려주세요!’, 보조 문구 ‘여행 시에 참고할게요.’.
- 사진, ‘보리 · 3살 · 대형견’ 요약.
- 질문 ‘보리와 차로 이동할 때 보통 얼마나 자주 쉬나요?’.
- 휠 피커: 시간/분, 예시 1시간 00분, 주변 값 0·2 / 55·05. 터치 스크롤과 키보드 조작 지원.
- ‘평소 다니는 동물병원’은 선택 항목. 검색 필드 ‘병원 이름 검색’.
- CTA ‘프로필 저장’.

## 5. M03 여행 계획(1)

- 헤드라인 ‘누구와 함께 떠날까요?’, 안내 ‘등록한 반려견을 눌러 선택해 주세요.’.
- 반려동물 원형 카드: 보리 선택, 루비 미선택, 추가.
- 보호자 사각 카드: 나/동행 보호자 선택, 추가.
- 선택 항목은 주황 테두리와 체크 배지. 하단 요약은 보호자 2명, 보리 1마리.
- CTA ‘선택 완료’.

## 6. M03 여행 계획(2)

- 프로필 요약 ‘보리와 함께하는 여행’, 변경 액션.
- 편집 문장: ‘양평으로, 11.18 – 11.19 1박 2일 보호자 2명과 떠나요’. 강조/밑줄 부분을 누르면 지역, 날짜, 인원 수정.
- 여행 테마 칩: 자연 속 휴식(선택), 산책, 액티비티.
- 카테고리 탭: 숙소(선택), 활동, 코스.
- 추천 장소 카드 목록은 세로 스크롤. 사진, 추천 배지, 이름, 지역/동반 조건/시설 포함.
- 장소 카드를 누르면 화면 7로 이동.

## 7. M03 장소 상세(3)

- 402×310 히어로 사진, 사진 위 뒤로/닫기와 이미지 이동 컨트롤.
- y≈274부터 상단 모서리 28px의 흰 바텀 시트.
- 장소 ‘숲속 스테이’, 지역 ‘경기 양평’, 보리 동반 안내.
- 체크 항목: 대형견 동반 가능 / 울타리 운동장·반려견 샤워실 / 입장 전 접종 증명 필요.
- 후기 미리보기와 별점, ‘더 보기’.
- 하단 ‘객실 예약은 별도로 진행해요’, ‘예약 안내’, CTA ‘이 여행지 추가하기’.

## 8. M03 여행 일정 확인(4)

- 헤드라인 ‘보리와 함께하는 양평 여행’, 날짜 ‘11.18 – 11.19 · 1박 2일’.
- 보리/보호자 요약과 ‘변경’.
- 날짜 탭 1일차/2일차.
- 타임라인: 출발지(미설정), 숙소 숲속 스테이(일정에 추가됨·예약 전), ‘+ 경유지·활동 추가’.
- 여행 테마 ‘자연 속 휴식’.
- 안내 ‘차량에서도 여행 계획을 볼 수 있어요.’, CTA ‘이 여행지 저장하기’.
- 화면 목적과 CTA 문구가 다소 불일치하므로 원문은 유지하고 PO 확인 항목으로 남깁니다.

## 9. M04 후기·장소 저장

- 헤드라인 ‘보리와 함께한 이곳, 어땠나요?’, 보조 문구.
- 장소 요약 카드: 사진, 숙소, 숲속 스테이, 양평, 보리 아바타.
- 뼈다귀 평점 5개, 예시는 4점 선택.
- ‘가는 길은 어땠나요?’ 다중 선택 칩: 편안하게 이동했어요(선택), 보리가 멀미했어요, 멀어요, 정체가 심했어요, 도로가 울퉁불퉁했어요.
- 한줄평 입력 ‘한줄평을 남겨주세요.’.
- CTA ‘후기 남기기’; 평점과 후기 저장 성공/실패 피드백 제공.
