cal# PET:A 차량 앱
 
Pleos Connect용 Kotlin 앱입니다. 실행 방법과 시연 순서는 [저장소 README](../README.md)를 참고하세요.

- 패키지: `com.peta.car`
- 화면과 흐름: `MainActivity.kt`, `PetaService.kt`
- 차량 신호: `vehicle/PleosVehicleStateSource.kt`
- 내비: `navi/PleosNaviGateway.kt`
- 모바일 연동: `remote/HttpPetaApi.kt`, `remote/TripJson.kt`
- 데모 배속과 서버 주소: `PetaConfig.kt`
